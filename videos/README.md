# Project Demonstration Videos

This folder contains demonstration videos of our **PLC-Controlled Automatic Water Filling System**.

## Project Overview
The system uses a PLC to automate the water-filling process using a conveyor, proximity sensors, a rotary arm, and an automatic filling mechanism.
